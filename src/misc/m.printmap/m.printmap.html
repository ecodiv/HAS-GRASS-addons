DESCRIPTION

m.printmap combines raster, vector, legend and label layers into a single PNG image. Like in the interactive map display, each layer can be made partly transparent.

The description and settings of layers are written to a small plain-text spec file. They are build up one layer at a time and then render, rather than describing the whole map in a single long command.

Working with the module therefore has two phases. The first phase consists of one or more steps to Build the spec file. Each run adds (or edits) one layer. The user picks a layer type, fills in that type's options and runs it to append the layerto the spec file. The second phase is to render the spec file (operation=render) to a PNG.

Give the spec file with new_spec to start a new map, or spec to read or update an existing one (these are mutually exclusive). Each type has its own tab of options in the GUI. You can fill in more than one, but note that only the options for the chosen type are used.

The module is designed to make building the spec file easy and then render it to a PNG. The spec file is, however, also a plain, human-readable list that you can write or edit by hand. This is handy for fine-tuning the exact position of an element, or for treating one spec as a template and producing many maps by only swapping the input map name(s).

When editing by hand, each setting is stored under the parameter name of the underlying display command, so you can look up its meaning in that command's manual. A vector layer uses the d.vect parameters (map, type, color, width, ...), a raster legend the d.legend parameters (raster, at, digits, flags, ...), a scale bar the d.barscale parameters, and so on. The longer GUI option names (e.g. legend_raster_digits) are also accepted as aliases and are converted to the canonical parameter name on the next write.

Layer types

The type option selects what a layer is:
  • solid: a full-canvas color fill, used as a background or, at a low opacity, as a tint over the layers below.
  • raster: a raster map.
  • vector: a vector map (areas, lines or points).
  • labels: text labels from a vector attribute column.
  • legend_raster, legend_vector: a legend for a raster or vector map.
  • barscale: a scale bar.
  • grid: a coordinate grid.
  • image: an external image (e.g. a logo or inset) placed in a box.

OPACITY AND LAYER ORDER

The opacity option controls the level of transparancy of each layer. Layers are drawn bottom to top in the order they appear in the spec file. operation=list prints that order with 1-based indices, which the position option then uses to insert, replace or delete a layer (position 0 means the end/top). See the operation and position parameters for details.

MARGIN AROUND THE MAP

At render time the margin option adds a border of the given number of pixels around the map. The margin is part of the mapping area: the width option gives the width of the map plus margin, and a solid background layer fills the whole mapping area (map and margin).

PLACING ELEMENTS OUTSIDE THE MAP

The at placement of the raster legend, vector legend and image layers is given in percent of the mapping area (0–100 spans the map plus any margin, origin bottom-left; so 0 is the outer edge of the margin). Values below 0 or above 100 place the element outside the mapping area: to the left or below for values < 0, to the right or above for values > 100. The output image is then automatically enlarged on that side to make room.

The width option sets the mapping-area width (map plus margin). With elements placed outside, the final PNG may be wider or taller.

The whole output image (the outer canvas, including the area around outside elements) is transparent by default. Give it a colour with the background option to fill it; unlike the solid layer, this covers the entire image, not just the mapping area.

WORKSPACE IMPORT

An existing GRASS GUI map composition can be turned into a spec file with m.printmap.gxw, which converts a workspace (.gxw) into the spec file format used by this module. You can then adjust the layers and render them.

NOTES

m.printmap requires the Python Pillow library.

m.printmap draws whatever the current region and mask are, so set those with g.region and r.mask before rendering.

This module is specifically convenient to compose a map using the GUI: you fill in each layer's options in its tab, without having to remember parameter names. The examples are for the commmand line, but it works the same way from the GUI. Build the spec one layer at a time, then later replace individual layers (Example 2) to reuse a layout for a new map. Use whichever fits you.

EXAMPLE

The examples use data from the North Carolina dataset, which you can download from here or in GRASS you can download it using the Download sample project button in the Data panel.

Example 1

Set the region and and build a spec file with four layers, then render it: 
# region
g.region raster=elev_state_500m

Initiate the spec file and set a lightgrey background layer. 

m.printmap new_spec=NC01.spec type=solid solid_color="#ececec"

Add the other layers. 

# Add elevation layer
m.printmap spec=NC01.spec type=raster raster=elev_state_500m

# Add layer with county boundaries
m.printmap spec=NC01.spec type=vector vector=boundary_county \
    color="49:49:49" font="arial" line_width=1 opacity=0.8

# Add legend
m.printmap spec=NC01.spec type=legend_raster \
    legend_raster_map=elev_state_500m legend_raster_at=12,16,6,40 \
    legend_raster_fontsize=10 legend_raster_flags=s,t

# Add logo
m.printmap spec=NC01.spec type=image image=grass-logo.png \
    image_at="5,30,90,99"

m.printmap spec=NC01.spec operation=render \
    output=m_printmap_01.png width=600 --overwrite

Print the list of layers that will make up the map. 

m.printmap spec=NC01.spec operation=list

Render the map to png. 

m.printmap spec=NC01.spec operation=render \
    output=m_printmap_01.png width=1200

The resulting map:

![](m_printmap_01.png)

Example 2

Now, let's replace the elevation layer (which as we have seen above, is the 2nd layer) and the legend (4th position) with the layer with average precipitation in January 2000. This is part of the NC Climate data set. 
# Replace the elevantion with rainfall layer
m.printmap spec=NC01.spec type=raster \
           raster=2000_01_precip@climate_2000_2012 \
           operation=replace position=2

# Replace legend
m.printmap spec=NC01.spec type=legend_raster \
    legend_raster_map=2000_01_precip@climate_2000_2012 \
    legend_raster_at=12,16,6,40 legend_raster_fontsize=10 \
    legend_raster_flags=s,t operation=replace position=4

# Render the map to PNG
m.printmap spec=NC01.spec operation=render \
    output=m_printmap_02.png width=600

The resulting map:

![](m_printmap_02.png)

Example 3

Repeate example 1, but place the legend right of the mapping area and move the logo to the left. We furthermore set a margin of 10 pixels. We'll create a new spec file NC03.spec for this. 
# region
g.region raster=elev_state_500m

# Add layers to file
m.printmap new_spec=NC03.spec type=solid solid_color="#ececec"
m.printmap spec=NC03.spec type=raster raster=elev_state_500m
m.printmap spec=NC03.spec type=vector vector=boundary_county \
    color="49:49:49" font="arial" line_width=1 opacity=0.8

# Add legend
m.printmap spec=NC03.spec type=legend_raster \
    legend_raster_map=elev_state_500m legend_raster_at=5,95,101,104 \
    legend_raster_fontsize=10 legend_raster_flags=s,t

# Add logo
m.printmap spec=NC03.spec type=image image=grass-logo.png \
    image_at="5,30,1,10"

Render the map to png. 

m.printmap spec=NC03.spec operation=render \
    output=m_printmap_03.png width=600 margin=10 --overwrite

The resulting map:

![](m_printmap_03.png)

Example 4

Repeate the previous example, but place both the logo and the legend below the mapping area, and set a general background to dark(er) grey. 
# region
g.region raster=elev_state_500m

# Add layers to file
m.printmap new_spec=NC04.spec type=solid solid_color="#ececec"
m.printmap spec=NC04.spec type=raster raster=elev_state_500m
m.printmap spec=NC04.spec type=vector vector=boundary_county \
    color="49:49:49" font="arial" line_width=1 opacity=0.8

# Add legend
m.printmap spec=NC04.spec type=legend_raster \
    legend_raster_map=elev_state_500m legend_raster_at=-7,-2,25,95 \
    legend_raster_fontsize=10 legend_raster_flags=s,t

# Add logo
m.printmap spec=NC04.spec type=image image=grass-logo-horizontal.png \
    image_at="-14,-3,2,20"

m.printmap spec=NC04.spec operation=render \
    output=m_printmap_04.png width=600 margin=10 background="#dfdfdf"

Render the map to png. 

m.printmap spec=NC04.spec operation=render \
    output=m_printmap_04.png width=600 margin=10
