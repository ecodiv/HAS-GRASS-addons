DESCRIPTION

i.in.svneo imports SuperView-NEO multispectral imagery into GRASS GIS and, when requested, performs radiometric and atmospheric preprocessing.

The module supports four-band SuperView-NEO products in the order blue, green, red and near infrared (NIR).

The module can be used in two main ways. For bottom-of-atmosphere (BOA) surface reflectance products, it imports the bands, optionally rescales the values, and writes raster metadata such as semantic labels, units and the acquisition timestamp. For digital number (DN) products, it can keep the DN values, convert them to top-of-atmosphere (TOA) radiance, estimate surface reflectance with dark object subtraction (DOS), or run i.atcorr using 6S atmospheric correction.

Metadata are read from either the NSO ISO 19115 XML file or the raw SuperView-NEO L1B MUX XML file.

NOTES

Input data

The module accepts either an external GeoTIFF through input or a set of already imported raster maps through input_bands. Exactly one of these options should normally be used.

When input is used, the GeoTIFF is imported with r.in.gdal. The input file must contain the four SuperView-NEO bands in the order blue, green, red and NIR.

When input_bands is used, the import step is skipped. The raster maps must be named basename.1, basename.2, basename.3 and basename.4.

The metadata option is required.

Processing levels

The processing_level option describes the input product. Use processing_level=boa for BOA surface reflectance products and processing_level=dn for DN products.

The target_level option describes the desired output. Examples include as_is, dn, radiance, dos1, dos2 and atcorr.

DN to radiance conversion

For DN products, TOA radiance is calculated per band as:

L = DN * GAIN + BIAS

Here L is TOA radiance, DN is the digital number, and GAIN and BIAS are calibration coefficients read from metadata.

Dark object subtraction

The values dos1 and dos2 estimate surface reflectance using dark object subtraction (DOS). This is an approximate method.

Atmospheric correction with i.atcorr

With target_level=atcorr, the module converts DN to radiance and runs i.atcorr using the 6S model.

EXAMPLES

Import a BOA product

i.in.svneo input=scene_boa.tif metadata=metadata.xml output=svneo \
processing_level=boa

Convert DN to radiance

i.in.svneo input=scene_dn.tif metadata=metadata.xml output=svneo \
processing_level=dn target_level=radiance

Run DOS1 correction

i.in.svneo input=scene_dn.tif metadata=metadata.xml \
geometry_metadata=l1b_mux.xml output=svneo \
processing_level=dn target_level=dos1

Run atmospheric correction

i.in.svneo input=scene_dn.tif metadata=metadata.xml \
geometry_metadata=l1b_mux.xml output=svneo \
processing_level=dn target_level=atcorr
